Lógica e Desenvolvimento de Softwares

O que é Lógica de Programação?

A Lógica de Programação é uma forma de organizar o pensamento para resolver problemas de maneira clara e ordenada.

Programar não começa pelo código!
Primeiro precisamos entender o problema, pensar em uma solução e organizar os passos necessários para chegar ao resultado.

O que é um algoritmo?

Um algoritmo é uma sequência de passos organizada para realizar uma tarefa ou resolver um problema.

Nós usamos algoritmos diariamente, mesmo sem perceber. Uma receita de bolo, por exemplo, possui uma sequência de etapas que precisa ser seguida para chegar ao resultado esperado.

Exemplo: fazer um sanduíche

1. Pegar o pão.
2. Colocar o recheio.
3. Fechar o pão.
4. Servir o sanduíche.

A Lógica no Desenvolvimento de Softwares

Na informática, os computadores não "pensam" sozinhos: eles apenas executam instruções exatas que nós fornecemos através de algoritmos.

⚡ O Papel do Algoritmo

É o mapa mental do sistema. Ele define as regras de negócio, como as decisões de um aplicativo ao receber um clique ou ao processar um dado.

🛠️ Criação do Software

O software é a construção final criada pela união de vários algoritmos escritos em uma linguagem que o computador entende.

Raciocínio Lógico

A lógica garante que o programa trate exceções, evite erros e entregue a resposta correta de maneira eficiente e rápida.
